Let’s use compute!

Harsh Gupta

Today let's train "Not Hotdog". It's a small model to detect if an image is a hotdog, or not!

If you don't know what Not Hotdog is, you should watch this clip from Silicon Valley 😊:

You can train it on compute.cx in four steps:

  1. Setup compute
  2. Prepare the data
  3. Setup the model for training
  4. Train the model and validate

Setup compute

Create an account, install the CLI, add credits.

curl -fsSL https://compute.cx/install.sh | sh
compute setup
compute credits add 10

Prepare the data

We already prepared the data for you. Grab it from Hugging Face:

theoriclabs/hot-dog-not-hot-dog

A slice of the train set. Hot dogs on top, everything else below.

In the training script, compute downloads the dataset on the machine during the run. You don’t upload images yourself.

Setup the model for training

Choosing a model architecture

We'll take a randomly initialized CNN, for no particular reason. Three conv blocks, adaptive pool, linear head. About 180k parameters. No pretrained weights. Small on purpose.

Choosing a loss function

Cross-entropy — the usual loss for a classifier. Two classes: hot_dog and not_hot_dog.

Train the model and validate

Grab the training script. That’s the only file you need. Or hand compute.cx/SKILL.md to your agent.

curl -fsSL https://raw.githubusercontent.com/theoriclabs/letsusecompute/main/posts/not-hotdog/train.py -o train.py

Want to read it first? train.py.

Dry-run first. It only prints the upload plan — no dollars yet.

compute run train.py::train --gpu cheap --dry-run

  train.py

gpu:         cheap
timeout:     1800s
image:       cuda_pytorch

Then run for real. Pass --gpu cheap and let the router pick. For this tiny CNN, cheap usually lands on a Vast.ai RTX 3090 around $0.15/hr. auto can pick a faster card if it thinks you’ll finish sooner. Default without --gpu is MI300X — too much machine for this toy.

compute run train.py::train --gpu cheap --timeout 1800 --wait

You’ll see the pick and the dollar quote before spend. Confirm if it looks right, or pass --yes.

Validating the results

When the run succeeds, the machine is gone. Weights don’t live on the VM. The intended pull is artifacts:

compute artifacts list <run_id>
compute artifacts get <run_id> <artifact_id> <version> --out ./weights

To keep a copy on Hugging Face, store a write token and run the secrets-backed entrypoint. Storing the secret is not enough — the function has to request it with Secret.from_name("hf"), or it never lands on the machine.

compute secrets set hf
compute run train.py::train_and_push --gpu cheap --timeout 1800 --wait

This guide’s checkpoint: theoriclabs/not-hotdog-cnn.

Want to train longer? Raise epochs and --timeout. You pay for billed minutes. Data stays on Hugging Face — compute doesn’t keep a volume for you. No wandb in this guide. No hosted inference API in this guide either; download the weights and run them locally.

After 50 epochs, train loss was 0.566. Test accuracy was 58.8% — barely above chance. Fine for a tiny randomly initialized CNN on 500 photos. Sample predictions from that run — three from each pile, test set, same checkpoint.
